# A_MNY9M.NET

Discord-бот для сообщества **Malenkie**, написанный на **.NET 10**.

Проект автоматизирует повседневные действия на сервере и добавляет инструменты для участников и администрации. Основное направление — управление голосовыми комнатами: их создание, персональная настройка и удаление.

Бот получает события через Discord Gateway, выполняет действия через Discord REST API и хранит настройки и данные о каналах в PostgreSQL.

## Технологии

- **.NET** — платформа приложения.
- **Discord.NET** — интеграция с Discord.
- **Entity Framework Core + Npgsql** — работа с PostgreSQL.
- **Serilog** — логирование.

## Структура проекта

- **A_MNY9M.Presentation** — точка входа и сборка приложения.
- **A_MNY9M.Integration** — клиент Discord, обработчики событий и команд.
- **A_MNY9M.Infrastructure** — работа с базой данных, сущности и репозитории.
- **A_MNY9M.Application** — прикладная логика.
- **A_MNY9M.Core** — общие типы и контракты.
